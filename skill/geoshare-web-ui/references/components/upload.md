# Upload 上传

Upload 用于选择图片或文件，并反馈待上传、上传中、成功和异常状态。基础组件只负责选择、展示与状态表达，真实上传请求由业务层通过 `beforeUpload`、`customRequest` 或受控状态接入。

## 变体

- `picture`：120 × 120px 图片选择框，支持空状态、悬停预览、上传中和已完成预览。
- `button`：按钮式上传，适合单个文件或轻量操作；可配合文件名和进度信息。
- `input`：输入框与上传按钮组合，适合需要显示当前文件名的表单。
- `list`：批量文件上传，包含拖拽区域、文件名、大小、状态和删除操作。

## 状态与规则

- 上传中使用进度或不确定加载反馈，阻止重复提交。
- 异常状态同时使用红色、错误提示和“重新上传”操作，不只依赖颜色。
- 完成状态保留文件名和删除入口；图片预览的查看、删除必须是可聚焦按钮。
- 禁用状态不可打开文件选择器，不显示悬停或按下反馈。
- 图片尺寸、文件数量、类型和大小限制由业务层校验，并在控件附近给出提示。

## API

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `type` | `picture \| button \| input \| list` | 上传外观，默认 `button` |
| `fileList` | `UploadFile[]` | 受控文件列表 |
| `accept` | `string` | 原生文件类型筛选 |
| `multiple` | `boolean` | 是否允许选择多个文件 |
| `disabled` | `boolean` | 是否禁用 |
| `maxCount` | `number` | 最大文件数量 |
| `onChange` | `(info) => void` | 选择、进度或状态变化时触发 |
| `onPreview` | `(file) => void` | 点击图片预览时触发 |
| `onRemove` | `(file) => boolean \| Promise<boolean>` | 删除文件前回调 |

## 可访问性

图片上传区域应提供按钮语义或键盘触发能力；操作图标使用真实按钮并提供 `aria-label`。状态变化通过可见提示和 `aria-live="polite"` 同步给辅助技术。
